## ✨ Features

- **Dark Premium Aesthetic**: A sleek `#02050A` ultra-dark theme with electric cyan and neon blue gradients.
- **GSAP Animations**: Complex scroll-triggered animations including horizontal scrolling galleries, sticky cards, and text reveals.
- **Lenis Smooth Scrolling**: Buttery smooth native scrolling experience integrated seamlessly with Next.js routing.
- **Interactive UI Components**: 
  - Dynamic intersection-observer Navbar with active states
  - Real-time Local Clock
  - 3D perspective hover cards
  - SVG Neon corner frames
- **Fully Responsive**: Flawlessly optimized across mobile, tablet, and desktop viewports.

## 🛠 Tech Stack

### Frontend & Core
- **Framework**: [Next.js (App Router)](https://nextjs.org/)
- **Library**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)

### Animation & Experience
- **Scroll Engine**: [Lenis](https://lenis.studiofreight.com/) for fluid smooth scrolling
- **Animation Engine**: [GSAP (GreenSock)](https://gsap.com/) & ScrollTrigger
- **Icons**: [React Icons (Lucide/Feather)](https://react-icons.github.io/react-icons/)

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

Ensure you have Node.js installed (v18.x or later).
```bash
node --version
npm --version
```

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/ArifKhanEver/Portfolio.git
   ```

2. **Navigate into the directory**
   ```bash
   cd Portfolio
   ```

3. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   # or
   bun install
   ```

4. **Start the development server**
   ```bash
   npm run dev
   ```

5. **Open the app**  
   Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.
